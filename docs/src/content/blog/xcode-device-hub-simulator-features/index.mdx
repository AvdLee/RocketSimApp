**Xcode Device Hub** replaces the standalone Simulator window in Xcode 27, but several Simulator features are missing. Shake, Slow Animations, familiar shortcuts, and drag-and-drop imports are workflows many iOS developers use every day.

I noticed how much these features matter after replying to developers in a [Reddit discussion about Device Hub](https://www.reddit.com/r/iOSProgramming/comments/1wgxeck/the_new_device_hub_is_awful_compared_to_the_old/). Their comments directly shaped RocketSim 16.5, which restores several missing Simulator workflows without requiring you to switch back to Xcode 26.

## Shake a Simulator in Device Hub

Device Hub has no obvious replacement for **Device → Shake** from Simulator.app. This can block you from testing undo prompts, debug menus, and custom shake interactions.

RocketSim 16.5 adds **Shake** to the Simulator menu in the menu bar and to the Comparing tab in the side window. You can also configure a global shortcut under **RocketSim → Settings → Shortcuts → Simulator**.

RocketSim shows the shortcut Simulator.app used before Device Hub: <strong>⌃⌘Z</strong>. It is only a suggestion, so you remain in control of your shortcuts. RocketSim does not assign one automatically.

Shake actions only target a Simulator. The button remains visible but disabled when you focus a physical device, preventing RocketSim from accidentally targeting another booted Simulator.

## Restore Device Hub shortcuts

Shake is not the only missing Simulator action. RocketSim 16.5 adds a dedicated Simulator shortcut group containing:

- Toggle Slow Animations
- Shake
- Toggle Light/Dark Appearance
- Simulate Memory Warning
- Shut Down Simulator
- Shut Down Other Simulators

You can also find all actions in the RocketSim menu bar. Shake, appearance, and memory warnings are available directly from the Comparing tab as well.

## Enable Slow Animations

**Slow Animations** makes transitions easier to inspect. You can spot an unexpected jump, verify that elements move together, and compare your implementation with a design.

Device Hub does not include this toggle, but it remains available in RocketSim's Comparing tab. You can enable it from the side window or assign a global shortcut under **Settings → Shortcuts → Simulator**.

The action applies to the focused Simulator and is unavailable for physical devices. Read the [Slow Animations guide](/docs/features/design-comparison/slow-animations/) for the exact controls and speed options.

## Drag files into Device Hub

Simulator.app accepted files anywhere on its window. Device Hub no longer provides the same general drop target, which affects much more than adding a photo.

RocketSim 16.5 turns its visible side window into a drop target for the active Simulator:

The drop target supports:

- `.apns` push notification payloads
- `.cer`, `.crt`, `.der`, and `.pem` root certificates
- Photos and videos
- `.app` bundles
- HTTP(S) and custom-scheme links

RocketSim processes every dropped item, so one invalid file does not block the rest. You will see a success notification, a partial-failure warning, or an import error when the operation completes.

Push payloads need a non-empty `"Simulator Target Bundle"` key containing your app's bundle identifier and an `aps` dictionary:

```json
{
  "Simulator Target Bundle": "com.example.MyApp",
  "aps": {
    "alert": "Testing a push notification"
  }
}
```

File imports are Simulator-only. RocketSim disables the drop target for a physical device because these `simctl` workflows are unavailable there. The [Device Hub file imports guide](/docs/features/app-actions/device-hub-file-imports/) lists every supported type and its requirements.

## More Device Hub tips

Some Device Hub workflows are different rather than missing. Switch to **Compact Mode** when you want a focused Simulator window similar to Simulator.app. RocketSim's side window works in expanded and Compact Mode, while screen-relative overlays require Compact Mode.

You can also open multiple Device Hub windows using **File → New Window** or <strong>⇧⌘N</strong>. This is useful when testing layouts side by side, even though the workflow is less discoverable than it was in Simulator.app.

The [Device Hub support guide](/docs/features/capturing/device-hub-support/) explains window modes, AI agent support, and the complete RocketSim integration. Apple also provides a broader overview in [Get the most out of Device Hub](https://developer.apple.com/videos/play/wwdc2026/260/).

## Conclusion

Xcode 27 Device Hub introduces a new way to work with Simulators and physical devices, but you should not have to give up the workflows that made Simulator.app productive. RocketSim 16.5 restores Shake, Slow Animations, appearance and memory-warning shortcuts, Simulator shutdown actions, and drag-and-drop imports.

Install the [latest RocketSim version from the Mac App Store](https://apps.apple.com/app/apple-store/id1504940162?pt=117264678&ct=xcode-device-hub-simulator-features&mt=8), open **Settings → Shortcuts → Simulator**, and assign the actions you use most.
